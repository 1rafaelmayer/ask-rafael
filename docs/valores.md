# Como trabalho e o que busco

Este arquivo responde às perguntas comportamentais e de fit — as que não têm
evidência em código.

## Como trabalho

- Gosto de trabalhar de forma organizada. Quando não há organização, tento provocar um esforço coletivo para
atingir esse fim, pois enxergo os benefícios de um projeto bem estruturado desde cedo.

- Acredito na transparência pois confio no trabalho que realizo. Quando um cliente pergunta qual é o status do projeto,
sempre tento ser sincero e compartilhar os pontos de atenção, já que o insucesso do projeto, também é insucesso meu.
Acredito que é melhor expor o problema para resolução do que jogar tudo pra de baixo do tapete. 

- Sempre tento buscar o valor o propósito da minha entrega. Qual problema estou resolvendo, é uma pergunta que sempre faço, e que muitas vezes
é o fator decisivo para me sentir motivado para continuar trabalhando bem.

## O que busco

- Resolver problemas reais das pessoas, e assim, me sentindo útil com um trabalho feito com propósito.
- Um bom equilibrio entre vida profissional e pessoal.
- Criar conexão com as pessoas.
- Ter a possibilidade de viver uma vida rica em experiências novas.

## Interesses fora do trabalho

- Toco guitarra numa banda de rock! Também toco outros insturmentos como violão, gaita, e um pouco de piano.
- Adoro esportes, e tenho feito aula de volei.
- Gosto de escrever e discutir sobre reflexões filosóficas.
- Tenho uma impressora 3D mas últimamente anda meio parada.
