Selected projects

Projetos em destaque

Hospital agents over WhatsApp

A large São Paulo hospital needed to offer routine services (check-in, quotes, exams, appointments) over WhatsApp, without the patient needing to know which internal system handles their request. I designed a multi-agent system with a coordinator that routes by intent to service-specific agents; for the check-in agent, my main focus, I built a state machine that scopes tools and prompt at each step, with state persisted in PostgreSQL. Stack: LangChain/LangGraph, LangSmith, FastAPI, PostgreSQL, Azure Container Apps. In production, serving thousands of patients a month.

Agentes hospitalares no WhatsApp

Um hospital de grande porte em São Paulo precisava oferecer serviços de rotina (check-in, orçamento, exame, consulta) por WhatsApp, sem que o paciente precisasse saber qual sistema interno atende seu pedido. Desenhei um sistema multiagente com um coordenador que roteia por intenção e agentes especializados por serviço; no agente de check-in, minha parte principal, implementei uma máquina de estados que restringe ferramentas e prompt a cada etapa, com estado persistido no PostgreSQL. Stack: LangChain/LangGraph, LangSmith, FastAPI, PostgreSQL, Azure Container Apps. Em produção, atendendo milhares de pacientes por mês.

Synthetic jury for campaign analysis

Testing an ad campaign with a real audience is expensive and slow. I built the entire AI pipeline of a synthetic-jury platform, blending ML and GenAI: k-modes clustering (scikit-learn) finds the audience profiles that actually exist in the data, each synthetic persona is anchored to one of those real clusters, and an AI agent handles the enrichment — biography and campaign-specific personalization — before it enters simulated interviews. Stack: FastAPI, PostgreSQL, Celery + Redis, scikit-learn, Google Gemini (pro/flash per step). In daily use for real campaigns.

Júri sintético para análise de campanhas

Testar campanha publicitária com público real é caro e lento. Construí o fluxo de IA completo de uma plataforma de júri sintético, que mistura ML e GenAI: k-modes (scikit-learn) clusteriza a audiência para achar os perfis que de fato existem nos dados, cada persona sintética é ancorada em um desses clusters reais, e um agente de IA faz o enriquecimento — biografia e personalização da persona com os dados da campanha — antes de ela entrar nas entrevistas simuladas. Stack: FastAPI, PostgreSQL, Celery + Redis, scikit-learn, Google Gemini (pro/flash por etapa). Em uso diário para campanhas reais.

ML-accelerated microscopy

High-resolution microscopy images are built point by point, which makes each scan slow and competes for time on expensive, high-demand equipment. I used machine learning to speed this up: measuring only a fraction of the points and using a Gaussian process model to reconstruct the rest of the image, with a statistical read on where the model is more or less confident. I ran a hyperparameter search to pick the kernel that best captured the pattern for each sample type, which was decisive for reconstruction quality. Published in Nano Letters 24(7), 2149 (2024).

Microscopia acelerada por machine learning

Imagens de microscopia em altíssima resolução são feitas ponto a ponto, e por isso demoram — cada imagem nova disputa tempo de um equipamento caro e concorrido. Usei machine learning para acelerar esse processo: medindo só uma fração dos pontos e usando um modelo de processos gaussianos para reconstruir o restante da imagem, com uma medida estatística de onde o modelo está mais ou menos confiante. Rodei uma otimização de hiperparâmetros para escolher o kernel que melhor captura o padrão de cada tipo de amostra, decisiva para a qualidade da reconstrução. Publicado na Nano Letters 24(7), 2149 (2024).
